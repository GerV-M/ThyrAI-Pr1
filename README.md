# Классификатор заболеваний щитовидной железы ThyrAI

Проект посвящён классификации заболеваний щитовидной железы с использованием методов машинного обучения. Модель обучается на медицинских данных и определяет одну из трёх категорий: нормальное состояние, гипертиреоз или гипотиреоз.

В проекте реализована модель случайного леса с наиболее подходящими для исходных датасетов параметрами.
Пользователь может менять гиперпараметры модели и предобработки путём редактирования файла params.yaml.

## Требования:
1. Linux или WSL c Ubuntu для запуска bash-скрипта (необязательно)
2. Python версии, указанной в pyproject.toml
3. uv
4. Исходные датасеты в каталоге data/

## Установка
1. Клонируйте репозиторий
```PowerShell
git clone https://github.com/GerV-M/ThyrAI.git
cd ThyrAI
```
2. Установите uv (в случае его отсутствия) и зависимости проекта
```PowerShell
git clone https://github.com/GerV-M/ThyrAI.git
cd ThyrAI
uv sync --locked
```
3. Проведите запуск с параметрами по умолчанию
```PowerShell
bash scripts/run.sh
```
Первый параметр в run.sh - путь к каталогу с исходными данными.
Второй параметр - каталог для сохранения предсказаний.

После выполнения программы формируются следующие файлы:
1. models/random_forest.joblib
2. metrics/metrics.csv
3. results/predictions.csv
