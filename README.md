# Классификатор заболеваний щитовидной железы ThyrAI

Проект посвящён классификации заболеваний щитовидной железы с использованием методов машинного обучения. Модели обучаются на медицинских данных и определяют одну из трёх категорий: нормальное состояние, гипертиреоз или гипотиреоз.

В проекте реализованы две модели:
1. Логистическая регрессия
2. Случайный лес

## Структура:
ThyrAI/
|-- data/       # Исходные датасеты
|-- metrics/    # Метрики качества моделей
|-- models/     # Сохранённые модели 
|-- results/    # Результаты предсказаний моделей
|-- scripts
    |-- run.sh      # Bash-скрипт запуска
|-- src/
    |-- main.py
|-- .gitignore
|-- pyproject.toml      # Зависимости и настройки проектов
|-- uv.lock     # Зафиксированные версии и зависимости
|-- README.md

## Требования:
1. Linux или WSL c Ubuntu для запуска bash-скрипта
2. Python версии, указанной в pyproject.toml
3. uv
4. Исходные датасеты в каталоге data/

## Установка
1. Клонируйте репозиторий
```PowerShell
git clone https://github.com/GerV-M/ThyrAI.git
cd ThyrAI
```
2. Установите uv (в случае его отсутствия) и зависимости проекта
```PowerShell
git clone https://github.com/GerV-M/ThyrAI.git
cd ThyrAI
uv sync --locked
```
3. Проведите запуск с параметрами по умолчанию
```PowerShell
bash scripts/run.sh
```
Первый параметр в run.sh - путь к каталогу с исходными данными.
Второй параметр - каталог для сохранения предсказаний.

После выполнения программы формируются следующие файлы:
1. models/logistic_regression.joblib
2. models/random_forest.joblib
3. metrics/metrics.csv
4. results/predictions.csv

## Дорожная карта
1. Ввод данных пациентом вручную для получения прогноза модели
2. Возможность ввода/изменения параметров модели для разработчиков
3. Добавление новых моделей
4. Создание веб-интерфейса
5. Визуализация результатов, объяснение предсказаний
